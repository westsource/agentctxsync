Quick Start

三分钟接入

一个开源项目该有的接入体验：一条命令、一个配置。

部署服务端

在自己的服务器上一键部署，生成工作区与 API Key：
bash deploy-server.sh

配置客户端

为每个 Agent 下载对应客户端包，填入工作区 Key：
export HERMES_SYNC_API_KEY=ws_xxx

重启 Agent

启动时自动增量拉取，远程为空时自动推送本地数据完成首次配对，之后每 5 分钟自动同步。

Web 管理

浏览器打开管理界面：会话查看器（Markdown 渲染）、一键导出/导入、设备状态一目了然。
